# 使用声明

Kiro Pool 用于管理已获授权的 Kiro 账号凭据。使用者应确保账号、激活码和设备均由本人合法控制，并遵守 Kiro 与 AWS 的服务条款。

切换账号时，应用会关闭 Kiro、刷新上游凭据、写入 Kiro 官方凭据文件，并将 Windows `MachineGuid` 修改为该账号永久绑定的值。此操作影响系统级机器标识，需要管理员权限。

本地切换失败时，应用会尝试恢复原始 `MachineGuid` 和切换前的凭据文件，并释放后端预留。若界面提示回滚失败，应停止继续切换并先完成手动恢复。

Access Token、Refresh Token 和 Client Secret 属于敏感信息。请勿通过截图、日志或公开渠道分享这些数据。
